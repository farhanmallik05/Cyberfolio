# Tech Stack Alpha

Evaluating core technological dependencies and module versions.

## Base Framework
- **Next.js 16.1.6**: Leveraging App Router and Turbopack for high-performance development and static generation.
- **Node.js 20+**: Runtime environment for building and deployment.

## Neural Interface (UI/UX)
- **TypeScript 5.7.3**: Strict typing for all components and data structures.
- **Tailwind CSS**: Utility-first styling for layout and basic mechanical accents.
- **CSS Modules**: Isolated styling for complex visual glitches, background grids, and hardware-acceleration required effects.
- **Framer Motion**: Orchestrating cinematic transitions and micro-animations.
- **Lucide React**: Primary icon engine.

## Data & Persistence
- **JSON Content Ledger**: Centralized data repository in `src/data/`.
- **GitHub API**: Dynamic repository statistics and project discovery.
- **Supabase**: Backend infrastructure for extended data persistence and analytics (pgvector support enabled).

## Environment Diagnostic
- **OS**: Windows (Local Dev)
- **Compiler**: Turbopack
- **Deployment**: Vercel / Static Export
