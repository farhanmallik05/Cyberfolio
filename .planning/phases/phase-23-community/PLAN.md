# Phase 23: Community Hub (/community)

## Why Last
Community is only viable once audience exists. Newsletter (Phase 21) builds the audience. Courses (Phase 22) creates invested members. Community without audience = ghost town. Sequence is: content → audience → community.

## Scope
- /community page
- Discord server link + preview of channels
- Open source contribution showcase (GitHub API — Farhan's public contributions)
- Monthly challenge (automation or AI topic)
- Community project gallery (submissions via GitHub PR or form)
- Job board for automation/AI gigs (simple Supabase-backed listings)
