# SEED-016: Pricing Calculator

## Concept
Interactive tool on /services where clients input project requirements and get an instant price estimate. Converts better than static pricing. Reduces back-and-forth on budget.

## Target Milestone: M4 (Phase 15)
## Trigger: Built inside Phase 15 (Services)

## Implementation
Inputs (step-by-step, not all at once):
1. Service type: Web / Automation / AI / Design
2. Complexity: Simple / Medium / Complex
3. Timeline: Rush (+40%) / Standard / Flexible (-10%)
4. Extras: SEO / Hosting Setup / Revisions+

Output:
- Price range in INR (₹X,000 – ₹Y,000)
- Price range in USD ($X – $Y)
- Estimated timeline in days
- CTA: "Get exact quote →" → contact form

## Theme Notes
Step indicators use --neon accent. Active step glows. Completed steps dim. Price output uses large Orbitron font in --neon color with glow effect. Uses existing .btn-primary for CTA.
